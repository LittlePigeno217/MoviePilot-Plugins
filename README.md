# 🎬 MoviePilot-Plugins

MoviePilot 第三方插件库，提供了一系列实用插件来增强 MoviePilot 的功能。

> ⚠️ 注意：本插件库为个人维护，代码结构参考了其他开源项目。推荐优先使用[官方插件库](https://github.com/jxxghp/MoviePilot-Plugins)。

> [!NOTE]
> 本文件由 `scripts/generate_readme.py` 根据 `package.json` 自动生成，请优先修改数据源而不是直接手改本文件。

- 标签：站点,签到,工具

### 2. ☁️ 115 轻量助手 (P115LiteAssistant)
- 版本：v1.3.2
- 功能：独立提供 115 登录、生活事件监控、STRM/302、目录上传秒传和签到；侧栏有一份媒体清单，一部电影一行、一季剧一行地管入库、做种与删除。
- 标签：115,STRM,上传,签到,工具
- 特点：
  - 📱 支持 115 扫码登录，Cookie 落盘加密存储
  - 👀 115 生活事件监控，自动同步本地 STRM
  - 🎬 STRM 生成与 302 直链播放，支持多端
  - ⬆️ 目录上传与秒传，监听整理完成事件自动增量上传
  - 🗂️ 通道式目录映射编辑器与目录选择器
  - 🔔 STRM / 上传 / 签到各自独立通知开关与消息类型
  - 🖼️ 入库通知走飞书卡片，海报与季集信息取自整理历史
  - 🗑️ 本地 STRM 删除后自动清理 115 云端文件与刮削残留，多层熔断 + 超量人工确认
  - 🚦 302 取链限流，请求失败自动重试
  - 📋 侧栏媒体清单全页：一部电影一行、一季剧一行，按入库 / 网盘 / 做种 / 通道筛选，逐行删 STRM、源文件或网盘文件
  - 👁️ 本地源目录实时监听：媒体 / 刮削文件一落到上传目录，安静 30 秒后自动增量上传，抢不到任务锁会排队补跑
- 更新说明：

  <summary>点击查看更新历史</summary>
  
  - v1.3.2: 重新规划上传触发链：文件事件不再触发一轮全量增量同步，改为文件级去重 + 稳定确认（2 秒×3 次签名）后逐文件短批次上传，传完一批立即释放网盘任务锁，pending 不再只增不减，页面再也不会被上传任务拖到打不开。按 DDSRem 参考实现补齐四组防护：上传队列满时不再静默丢任务（自动转全量重扫回退）；反向删除确认明细不再截断头部（完整分页保存，坏分页信息直接 fail-closed 拒确认，不会把列表打崩）；同一删除批只允许一个确认人（原子 claim token，checkpoint 单调不回退，执行中的批不能驳回但会明确说明）；任务面板新增 holder/心跳/当前位置/进度，长任务卡在哪一步一眼可见，还能在 /task/cancel 协作取消。stability、删除监听、sweep 三类等待区全部加上限与「已满」标记，溢出转全量巡检不丢任务；queue_upload 与 trigger_upload 旧自动排队语义恢复兼容，外部调用不破坏；上传执行链接入进度回调，取消在文件边界安全生效，当前原子操作不被强杀。

  - v1.3.0: 侧栏多了一个全页入口：媒体清单 —— 一部电影一行、一季剧一行，按入库 / 网盘 / 做种 / 通道筛选，状态都带计数；逐行删 STRM、源文件或网盘文件，还在做种的删不动，网盘核对撞上访问上限会自己停。清单顶上有一行跟着筛选走的总计（已入库 / 未入库 / 源文件可回收 / 网盘上没了 / 等你确认），库里有新问题时才发通知。整页铺满宿主区域，搜索、筛选和排序吸在顶部，默认按入库时间升序，资源列表分页显示。本地源目录实时监听：媒体 / 刮削文件一落到上传目录，安静 30 秒后自动增量上传，抢不到 115 任务锁会排队补跑，不漏传。

## 📖 使用说明

1. 在 MoviePilot 中安装插件
2. 根据插件说明配置相关参数
3. 启用插件并设置定时任务（如需要）

3. 如遇到问题，请先查看插件说明或提交 Issue
