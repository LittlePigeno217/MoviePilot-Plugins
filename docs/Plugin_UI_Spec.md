# 插件界面规范

这一仓的插件装在同一个 MoviePilot 里，从同一个插件列表打开。用户开哪个都该是同一套读法，
所以「同一个区域长同一个样」是硬规格，不是风格偏好。

**新插件从 [`templates/v2-vue-plugin`](../templates/v2-vue-plugin/) 起手**，它已经按本规范
配好了底座、标题栏、运行台与设置页两套外壳。改完跑一次 `python scripts/check_ui_spec.py`
核对数值。

现有实现可以直接对照：[`plugins/checkin`](../plugins/checkin/src/)、
[`plugins/p115liteassistant`](../plugins/p115liteassistant/src/)。

## 1. 底座：颜色一律从宿主主题取

**这个文件里不允许出现任何写死的颜色值。** 所有颜色都从 MoviePilot 运行时注入的 Vuetify
主题变量读取，浅色 / 深色 / 紫色主题切换时插件自动跟随：

| 用途 | 变量 |
|---|---|
| 面板 | `rgb(var(--v-theme-surface))` |
| 凹槽 | `rgb(var(--v-theme-background))` |
| 强调色 | `rgb(var(--v-theme-primary))` |
| 状态 | `rgb(var(--v-theme-success) / warning / error)` |
| 等你决定 | `rgb(var(--v-theme-info))` |
| 细分隔线 | `rgba(var(--v-border-color), var(--v-border-opacity))` |
| 次要文字 | `rgba(var(--v-theme-on-surface), var(--v-medium-emphasis-opacity, 0.6))` |

Vuetify 以裸 `r,g,b` 三元组输出这些变量，所以 `rgba(var(--x), .12)` 可以直接取透明度。

选择器全部收敛在插件自己的命名空间下（`.ck` / `.p115` / 新插件用自己的前缀），不泄漏到宿主。
用到 `v-dialog`、`v-select` 这类会被 teleport 到 body 的组件时，令牌要再挂一个 `.<前缀>-portal`
类，弹窗根节点带上它才能继承同一套值。

## 2. 数值：这几行必须逐字相同

| 部件 | 规格 |
|---|---|
| 面板 | 间距 18 · 头 `16px 18px 0` · 身 `12px 18px 18px` · 圆角 12（小件 8） |
| 读数格 | 内边距 `14px 14px 12px` · 值 15px/700 · 条 gap 12 · `minmax(150px, 1fr)` |
| 记录卡 | 栅格 `auto-fill minmax(240px, 1fr)` gap 10 · 内边距 `11px 13px` · 圆角 8 |
| 读数丸 | `1px 7px` · 圆角 999 · 11px · 极淡底 · 细边 |
| 小标签 | 10px/700 · 字距 `0.18em` · 次要色（中文用不上 uppercase 与等宽） |
| 空态 | 虚线框 `24px 18px` · 居中 13px 次要色 |
| 等你决定 | 左侧 2px 竖线 + 极淡底，颜色用 `info` 不用红（审阅态不是报错态） |
| 设置页外壳 | 导轨 `13rem` + `minmax(0, 1fr)` · gap 16 · 内边距 16 · 导轨吸顶 `top: 58px` |
| 分区按钮 | 内边距 `9px 10px` · 圆角 8 · 标签 13px/600 · 备注 11px |
| 窄屏断点 | 设置页 720px（导轨转横向可滑）· 标题栏状态格 560px（隐藏） |
| 动效 | 入场 rise 260ms 阶梯 70ms · 状态线 trace 520ms · 呼吸 3.2s |

## 3. 角色类名：一一对应，只差前缀

```
*-section-title   区块标题 15px/700
*-hint            标题下那句说明 12px 次要色
*-label           小标签
*-mono            等宽 + tabular-nums（竖着扫的数字列）
*-muted           次要色
*-panel           面板（配 __head / __body）
*-pill            读数丸（配 --on / --warn / --bad / --hold）
*-empty           空态：问过了，确实没有
*-probe           未知态：还没问到
*-enter           入场动画（配 --2 / --3 / --4 阶梯）
```

**空态与未知态必须长得不一样。** 虚线盒 = 问过了确实没有，可以动手；轻量一行 = 还没问到。
状态读不到时显示「还没有记录」是把读不到说成没有，等于替用户下结论。三态各写一句：

```js
const ready = ref(false)     // 问过了
const failed = ref(false)    // 问了但没答上来
const trusted = computed(() => ready.value && !failed.value)
const probeNote = computed(() => failed.value ? '状态没读到。点右上角的刷新重试一次。' : '正在读取…')
```

## 4. 两套外壳

插件只有两个视图，标题栏上一个按钮来回切。

### 4.1 标题栏

MoviePilot 的 vue 渲染分支不提供标题和关闭按钮（`VCardText` 用了 `pa-0`），所以这些控件必须
由插件自己提供。三块：身份（色块 + 名称 + 视图名）、状态、工具（刷新 / 切换 / 关闭）。

```
┌──────────────────────────────────────────────────────────┐
│ [签] 自用签到          ● 今天 1 个没签上   ⟳  ⇄  ✕        │
│      运行台                                               │
└──────────────────────────────────────────────────────────┘
```

**右对齐靠身份块 `flex: 1 1 auto` 吃掉空白，不要靠状态那一格的 `margin-inline-start: auto`。**
状态格在 ≤560px 时是 `display: none`，auto 外边距跟着消失，三个按钮就滑到中间去了。
状态格与工具格都 `flex: none`。

### 4.2 运行台

```
标题栏
──────────────────────────────────────────────
读数条    一格一个「现在能不能干活」的答案，顶部 2px 状态细线
手动区    一句「当前空闲，按需触发」+ 一排 outlined 按钮
等你决定  只在真有事等人时出现（左侧竖线 + info 底）
清单/明细 插件自己的主题内容
执行记录  卡片栅格，见第 5 节
```

### 4.3 设置页

```
标题栏
──────────────────────────────────────────────
┌────────────┬─────────────────────────────┐
│ 分区导轨    │  分区面板                    │
│ 图标 标签   │  ┌ *-panel ───────────────┐ │
│      状态   │  │ 标题 + 说明             │ │
│            │  │ 表单                    │ │
│ ◀ 当前分区  │  └────────────────────────┘ │
└────────────┴─────────────────────────────┘
页脚  保存后立即生效，不用重启 MoviePilot。   放弃改动  保存配置
```

导轨上每个分区带一行状态（`已开启` / `待填写` / `已关闭` / `2 条`），不点进去就知道哪个还没配好。
切换分区用 `:key="section"` 让面板重新挂载、入场动画重播一次；**不要用 `<Transition>`** ——
`out-in` 会给切换硬加一段离场延迟，设置页的手感应该是「立刻到」。

## 5. 执行记录卡片

两个插件逐字相同的三段。多出来的东西（比如可展开的明细）加在第三段之后。

```
┌──────────────────────────────┐
│ 云端清理              8.4 秒 │  ① 左：一句结论或任务名（着色）
│ 2026-09-03 22:04             │     右：一个次要读数（耗时 / 规模），mono 次要色
│ [云端删了 4] [刮削文件 11]    │  ② 完整时间戳，mono 11px 次要色
└──────────────────────────────┘  ③ 一排读数丸
```

- **只报有意义的那几个数，避免整排 0。** 出事的那颗丸子着红。
- 什么都没发生时给一句话（`已经是最新的` / `没有变化`），不要空着。
- 时间戳写完整的 `YYYY-MM-DD HH:MM:SS`，不要只写时分 —— 记录是拿来回溯的。

## 6. 词表：通知、运行台、设置三处同名

| 概念 | 用词 | 不要用 |
|---|---|---|
| 刮削产物 | 刮削文件 | 附加、刮削、sidecar |
| 删掉本地已不存在的 | 清理 | 删掉、移除 |
| 等人工确认 | 等你确认 | 待确认、待处理 |
| 文件待着的那个地方 | 网盘 | 云端 |
| 115 这个服务本身 | 115（115 授权、115 回收站） | — |
| 在网盘上删了 | 网盘删了 | 云端删除、115 上删了 |
| 记录对不上文件 | 对不上网盘文件 | 溯源缺失、对不上文件 |
| 网盘本来就没有 | 网盘上没了 | 云端已无、115 上没了 |
| 耗时 | `8.4 秒` / `不到 1 秒` / `2 分 15 秒` | `8400ms`、`8.4s` |
| 开关态 | 已开启 / 已关闭 | 已启用 / 已停用 |
| 没配好 | 待填写 | 未配置、配置待完善 |
| 两个视图 | 运行台 / 设置 | 台账、面板、控制台 |

数字两边留一个空格，数字和单位之间也留：`近 7 天`、`+128 MB`、`10 集齐了`、`9 小时 30 分钟后`。
宿主给的字符串（比如「下次执行」的倒计时）也要过一遍这个规则再显示。

**一个地方只有一个名字。** 同一处存储别在标题里叫「云端」、正文里叫「115 上」、清单里叫
「网盘」—— 一条通知里出现两个地名指同一处，读的人得先确认它们是不是一回事。真机上踩过这个：
标题「云端删了 3 个文件」配正文「115 上跟着删了 3 个」，同一个数配两个地名说了两遍。

**破坏性动作要说清能不能撤回。** 「删了 20 个文件」之后读的人第一个念头是「找得回来吗」，
那句话必须在通知里，不能只在运行台里。

## 7. 文案

界面上的字是设计材料，不是装饰。

- **从用户那一侧写。** 说人管得着的东西，不说系统怎么实现的：管的是「通知」，不是
  「webhook 配置」。
- **按钮说清按下去会发生什么**，并且一路同名：按钮写「保存配置」，提示就写「配置已保存」。
- **报错说清出了什么事、下一步怎么办**，不道歉、不含糊。原话过长时在第一个说得完整的
  分句处收住 —— 「结论，加一串建议」这种句式，通知里只留结论。
- **原话是源码就别抄出来。** 站点报错时拿不到弹窗文案、退回整页正文的情况真实发生过，
  结果通知里出现一句 `body,div,html,p,span{margin:0…`。见到花括号、尖括号、`属性: 值;`
  就当没原因，指路去记录里看。
- **空态是行动的邀请**，不是一句「无数据」：`还没有执行记录。跑一次任务后这里会记下每次的结果。`
- 句子短、动词实、不堆形容词。一个元素只干一件事：标签就标签，例子就例子。

## 8. 动效

只动 `transform` 与 `opacity`（都在合成层，不触发布局与重绘），全部一次性播放
（`fill-mode: both`），播完不留常驻动画，空闲时合成开销为零。

三种记号各说一件事，除此之外不引入第四种视觉隐喻：

| 记号 | 含义 |
|---|---|
| 2px 横线在顶部 | 这一块此刻的状态（亮 = 正常 / 成了） |
| 横线扫过一次 | 面板刚挂载，读数还在建立 |
| 2px 竖线在左侧 | 这块在等一件事发生 |

每个插件可以有**一个**自己的主题图形（签到是一格一天的打卡带，115 是一格一集的库存带），
用同一套 `■ ▣ □ ·` 记号，换的只是单位。

命名空间里挂一处总闸，系统开了「减少动态效果」就把所有动画与过渡按掉 —— 只在这条媒体查询里
用 `!important`，无障碍覆盖高于组件意图：

```scss
@media (prefers-reduced-motion: reduce) {
  .<前缀> *, .<前缀> *::before, .<前缀> *::after { animation-duration: 1ms !important; /* … */ }
}
```

## 9. 质量底线

- 键盘焦点可见（`:focus-visible` 描边用强调色，`outline-offset` 留 1–3px）。
- 窄屏能用：读数条降列、导轨转横向、状态格隐藏、长路径可截断或横向滚动。
- 数字列用 `font-variant-numeric: tabular-nums`，竖着扫才对得齐。
- 装饰性图形加 `aria-hidden="true"`；导轨用 `<nav aria-label>` + `aria-current`。
- 前端产物别把整份 Vuetify 打进去（宿主已经有了）。两个现有插件的 `vite.config.js` 里有
  相关注释可抄。

## 10. 自查

```bash
python scripts/check_ui_spec.py        # 核对各插件的规范数值是否一致
```

无头截图自审（本机没有 playwright，用 Edge）：

```bash
EDGE="/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe"
"$EDGE" --headless=old --force-prefers-reduced-motion --disable-gpu --hide-scrollbars \
  --user-data-dir="C:/Users/<你>/AppData/Local/Temp/uiedge" \
  --window-size=900,1600 --virtual-time-budget=4500 \
  --screenshot="C:/Users/<你>/AppData/Local/Temp/shots/x.png" "http://localhost:<端口>/#page"
```

两个必须加的开关：`--headless=old`（`=new` 不按 `--window-size` 渲染）和
`--force-prefers-reduced-motion`（否则截到入场动画中途，整块看着像坏了）。
调试壳不加载 mdi 字体，所以截图里 `<v-icon>` 是空的，真实 MoviePilot 里有。
